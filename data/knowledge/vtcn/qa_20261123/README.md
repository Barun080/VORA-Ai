## ขั้นตอนใช้งานกับระบบจริง (ทำตามลำดับ)
1. สำรองฐานข้อมูล: `backup_db.bat`
2. ปิดข้อมูลตัวอย่างที่ติดมากับการติดตั้ง (FAQ ปลอม เช่น "งานทะเบียนอาคาร 1 ชั้น 1"):
   `python scripts\retire_seed_samples.py` (ดูก่อน) → `--apply` · ย้อนกลับ `--undo ไฟล์`
3. หลังบ้าน → **ฐานความรู้ AI → นำเข้า CSV** → เลือก `kb_import_20261123.csv` → รายการเข้ามาเป็น "รอตรวจ" → ตรวจแล้ว **อนุมัติ**
4. ใน "ฐานความรู้ AI" ให้ **ปฏิเสธ/แก้** รายการเก่าที่ล้าสมัย (จาก `vora_import_knowledge.csv` ชุดเดิม) เช่น
   "มีแผนกอะไรบ้าง" ที่บอก 17 แผนก (หน้าเว็บปัจจุบันมี 18 แผนกวิชา) และข้อความค่าเทอม/รอบสมัครเก่า
5. นำข้อมูลไม่แน่นอน/เก่าเข้ากล่องตรวจข้อมูล: `import_sandbox.bat` (ดูก่อน) → `--apply` แล้วตรวจที่หลังบ้าน → ปัญญาประดิษฐ์ → กล่องตรวจข้อมูล (ดู docs/feature-sandbox.md)
6. นำเข้ากรณีทดสอบ: `python scripts\import_eval_cases.py` (ดูก่อน) → `--apply` · ย้อนกลับ `--undo ไฟล์`
7. หลังบ้าน → ฐานความรู้ AI → สร้างดัชนีใหม่ (หรือรีสตาร์ต `start.bat`) → หน้า "ประเมินผล AI" กดรัน
8. ตั้งค่า → ข้อมูลติดต่อ: แก้ "ติดต่องานประชาสัมพันธ์ อาคาร 1 ชั้น 1 โทร 0-0000-0000" (ค่าตัวอย่าง) เป็นข้อมูลจริง
   และใส่เบอร์ 0-5471-9552 ในช่องโทรศัพท์

# คำถามที่ยังไม่มีข้อมูลจริง — รอทีมยืนยัน (23 พ.ย. 2569)

ค้นจากเว็บไซต์วิทยาลัยและแหล่งทางการแล้วไม่พบ หรือพบแต่ไม่ชัด จึงเว้นคำตอบไว้ (ห้ามเดา) — ส่งข้อมูลจริงพร้อมแหล่ง (เอกสาร/ประกาศ/ผู้ให้ข้อมูล) แล้วจะเติมให้

| id | คำถาม | สิ่งที่ต้องการ |
|---|---|---|
| Q001 | วิทยาลัยเปิดกี่โมง | ไม่พบเวลาทำการของวิทยาลัยบนเว็บไซต์ พบเพียงคำว่า 'ในวันเวลาราชการ' (S15) — ขอเวลาทำการจริงจากงานบริหารทั่วไป |
| Q015 | แผนกนี้อยู่ตึกไหน | ไม่มีข้อมูลอาคาร/ห้องบนเว็บ — ขอผังวิทยาลัยหรือชื่ออาคารของแต่ละแผนก |
| Q017 | ห้องปฏิบัติการคอมอยู่ตรงไหน | ขอตำแหน่งห้องปฏิบัติการ |
| Q027 | เรียนยากไหม | ไม่มีข้อมูลที่อ้างอิงได้ — แนะนำให้ VORA ตอบตามความจริงว่าไม่มีข้อมูลและแนะนำถามครูแนะแนว (ทีมเขียนข้อความได้) |
| Q048 | ค่าใช้จ่ายเท่าไหร่ | ไม่พบค่าเทอม/ค่าสมัครบนเว็บ — ขอจากงานการเงิน/งานทะเบียน |
| Q069 | ห้องทะเบียนอยู่ไหน | ขอตำแหน่ง |
| Q070 | ห้องผู้อำนวยการอยู่ไหน | ขอตำแหน่ง |
| Q071 | ห้องธุรการอยู่ไหน | ขอตำแหน่ง |
| Q072 | ห้องพยาบาลอยู่ไหน | ขอตำแหน่ง |
| Q073 | ห้องประชุมอยู่ไหน | เว็บเคยกล่าวถึง 'หอประชุมวิษณุรักษ์' แต่ไม่มีตำแหน่ง |
| Q074 | โรงอาหารอยู่ตรงไหน | ขอตำแหน่ง |
| Q075 | ห้องน้ำอยู่ไหน | ขอตำแหน่ง (เทียบกับจุดตั้งหุ่น) |
| Q076 | อาคารแผนกคอมอยู่ไหน | ขอตำแหน่ง |
| Q077 | ถ้าจะไปฝ่ายวิชาการต้องไปทางไหน | ขอตำแหน่ง/เส้นทางจากจุดตั้งหุ่น |
| Q078 | จุดรับสมัครอยู่ตรงไหน | ขอตำแหน่ง |
| Q096 | ใครเป็นคนสร้างเธอ | ขอชื่อทีม/ครูที่ปรึกษาที่ต้องการให้ VORA พูด |

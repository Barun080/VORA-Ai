# กล้องจำป้าย: รายละเอียดตามประเภท + ป๊อปอัปนำเสนอ + ถามต่อ (24 พ.ย. 2569)

**สวิตช์:** `VORA_VISION_DETAIL=1` (รายละเอียด/ป๊อปอัป/ถามต่อ · 0 = ตอบแบบเดิม) · `VORA_VISION_UNKNOWN=1` (บันทึกภาพที่ยังไม่รู้จัก · 0 = ไม่เก็บภาพ)
ตั้งเวลาปิดป๊อปอัป: `frontend/kiosk/kiosk-config.js` → `vision.popupIdleMs` (ค่าเริ่มต้น 60000 = 60 วินาที)

## เจ้าหน้าที่ (หลังบ้าน → สอนกล้องจำป้าย)
1. ตารางป้าย → ปุ่ม **รายละเอียด** → ขั้นที่ 1 **เลือกประเภท** → ขั้นที่ 2 กรอกช่องของประเภทนั้น
   | ประเภท | ช่อง |
   |---|---|
   | 🪧 ป้าย/สัญลักษณ์ | ชื่อ · ความหมาย · แผนก/หน่วยงาน · ติดตั้งที่ไหน · เพิ่มเติม |
   | 📢 โปสเตอร์/ประกาศ | หัวข้อ · รายละเอียด · วันเริ่ม–สิ้นสุด · สถานที่ · ผู้จัด · ใครเข้าร่วมได้ · วิธีสมัคร · ลิงก์ (ทำ QR) · วันหมดอายุ |
   | 📸 กิจกรรม/ภาพเหตุการณ์ | ชื่อ · วันที่ · สถานที่ · ผู้เกี่ยวข้อง · รายละเอียด · ผลงาน/รางวัล |
   | 🔧 วัตถุ/อุปกรณ์ | ชื่อ · ใช้ทำอะไร · แผนกที่ใช้ · ข้อควรระวัง · เพิ่มเติม |
   | 🏆 ผลิตภัณฑ์/ผลงาน | ชื่อ · ผู้ผลิต/แผนก · จุดเด่น · ราคา/ช่องทางซื้อ · รางวัล · เพิ่มเติม |
   โปสเตอร์/กิจกรรม **ผูกกับข่าว** ได้ (ช่องที่เว้นว่างใช้หัวข้อ รายละเอียด วันที่ สถานที่ รูปจากข่าว) · **รูปหลายรูป** แสดงเป็นสไลด์ (ไม่มีรูป = รูปข่าว → ภาพตัวอย่างตอนสอนกล้อง)
2. บันทึกแล้วจะแสดง "ตัวอย่าง: หุ่นยนต์จะพูดว่า …" · ป้ายที่ยังไม่กรอกรายละเอียดตอบแบบเดิม (แนะนำสาขา/เปิดข่าว/ข้อความ)
3. ส่วน **ภาพที่ผู้ใช้ถามแต่ยังไม่รู้จัก**: เลือกป้าย → เพิ่มเป็นตัวอย่าง → กด "ฝึกโมเดลจำภาพใหม่" · ไม่ใช้/ลบได้ (เก็บล่าสุด 300 ภาพ ในเครื่องนี้เท่านั้น)

## ผู้ใช้ (หน้าจอหุ่น)
- ชูสิ่งที่สอนไว้ → พูดสรุป + **ป๊อปอัปนำเสนอ** (สไลด์รูปซูมช้า วงแสง ประกาย การ์ดรายละเอียด QR ปุ่มคำถามแนะนำ แถบนับเวลา)
- ขณะป๊อปอัปเปิด: ถามเรื่องสิ่งนั้น ("จัดที่ไหน" "ราคาเท่าไหร่" "อันนี้ใช้ทำอะไร") = ตอบจากช่องที่กรอกเท่านั้น ·
  ไม่มีข้อมูล = บอกตรง ๆ + บันทึกเป็นคำถามที่ตอบไม่ได้ `[ชื่อสิ่งนั้น] คำถาม` · ถามเรื่องอื่น ("ค่าเทอมเท่าไหร่") = ตอบตามปกติและปิดป๊อปอัป
- ปิดเมื่อ: กด × / พูด "ปิด" "พอแล้ว" "ขอบคุณ" / ไม่มีคนถามต่อ 60 วินาที / ไม่มีคนหน้าจอ · โชว์สิ่งใหม่ระหว่างเปิดอยู่ = ยังไม่สลับ (ปิดก่อน)
- ถาม "นี่คืออะไร / รู้จักอันนี้ไหม" พร้อมชูของ → กล้องถ่ายภาพนิ่งจำแนก: รู้จัก = แสดงป๊อปอัป · ไม่รู้จัก = บอกว่ายังไม่รู้จัก + เก็บภาพย่อให้เจ้าหน้าที่

## ความเป็นส่วนตัว
ภาพย่อ (≤ 192 px) และเวกเตอร์ส่งไปเซิร์ฟเวอร์ในเครื่องเดียวกันเท่านั้น ไม่ส่งไปบริการภายนอก ไม่ใช้จดจำใบหน้า · เกิดเฉพาะเมื่อผู้ใช้ถามเอง · ปิดได้ `VORA_VISION_UNKNOWN=0`

## หน้าหลังบ้าน "สอนกล้องจำป้าย" แบบใหม่ (24 พ.ย. 2569)
- แถบ 4 ขั้นด้านบน: ① เพิ่มสิ่งที่จะสอน → ② เก็บภาพ (≥ 10 ภาพ/รายการ) → ③ ใส่รายละเอียด (ป๊อปอัป) → ④ ฝึกโมเดลแล้วทดสอบ · ขั้นที่ยังไม่เสร็จขั้นแรกมีกรอบสีส้ม กดแล้วไปแท็บนั้น
- แท็บ: สิ่งที่หุ่นยนต์รู้จัก (การ์ด) / เก็บภาพตัวอย่าง / ฝึกโมเดล / ภาพที่ยังไม่รู้จัก
- การ์ดแต่ละรายการ: ภาพปก ประเภท แถบจำนวนภาพ "เมื่อเห็น" และ "ขั้นถัดไป" พร้อมปุ่มหลักของขั้นนั้น
- เพิ่มรายการกรอกแค่ชื่อ — รหัส (label) สร้างให้อัตโนมัติ · ปุ่ม "เพิ่มพื้นหลัง" สร้างรายการ action=none
- แท็บฝึกโมเดลมีเช็กลิสต์ และบอก "มีภาพใหม่ยังไม่ได้ฝึก" (เทียบภาพของรายการที่มี ≥ 3 ภาพ กับ n_samples ของโมเดลที่ใช้อยู่)
- API เดิมทั้งหมด เพิ่มเพียง `GET /api/admin/vision/samples?limit=` (ค่าเดิม 200) สำหรับภาพปก
- สำรองไฟล์เดิม: `_backups/vision-ui-20261124/` (admin.js, admin.css, admin.py) — คืนค่าได้โดยคัดลอกกลับ

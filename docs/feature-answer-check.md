|---|---|---|

| ค่าใช้จ่ายเท่าไหร่ | ตอบเรื่องรอบสมัคร (มีแต่เลขปี) | ต้องมี "บาท/ฟรี" จึงนับเป็นคำตอบราคา |
| มีการแข่งขัน STEM ไหม / Python คืออะไร | ตอบเรื่องอื่นที่คล้าย | คำภาษาอังกฤษที่เป็นหัวเรื่องต้องอยู่ในข้อมูล |
| สมัครออนไลน์ได้ไหม / ต้องสอบไหม | จับคู่ด้วยคำลงท้าย "ได้ไหม" | คำถามสั้น + คะแนนต่ำ → แก่นคำถามต้องอยู่ในคำถามของข้อมูล |
| แผนกนี้มีสาขาอะไรบ้าง (ถามต่อ) | รายชื่อทุกสาขา | ใช้สาขาที่เพิ่งคุย → ค้น "แผนก<ชื่อ>มีสาขาอะไร" |
| เรียนกี่ปี (ถามต่อ) | ตอบเฉพาะ ปวส. | ผู้ใช้ไม่ระบุระดับ → ใช้ข้อมูลแบบรวม ปวช. 3 ปี / ปวส. 2 ปี |
| แผนกเมคคาฯ เปิดระดับไหน | ระดับของแผนกอิเล็กฯ | ไม่ใช้ FAQ ของสาขาอื่น · "ระดับไหน" ต้องมี ปวช./ปวส. |
| มีสาขาที่ทำเกมมั้ย / ดูข่าวล่าสุดตรงไหน | รายการสำเร็จรูป | FAQ ที่ตรงมาก (≥ 0.62) ชนะ · คำถามรายการล้วนยังใช้ข้อมูลสด |
| งานเริ่มกี่โมง | บอกเวลาปัจจุบัน | คำว่า งาน/เริ่ม/จัด/แข่ง/พิธี ไม่ใช่ถามนาฬิกา |
| งานนี้จัดที่ไหน / วันไหน (หลังอ่านข่าว) | ไม่ตอบ | ตอบจากสถานที่/วันที่ของข่าวนั้น (ไม่มี = บอกตรง ๆ) |
| เธอค้นข้อมูลจากอินเทอร์เน็ตได้ไหม | สั่งค้นเว็บ | เป็นคำถามความสามารถ ไม่ค้น |
| ท้ายคำตอบ "ไม่มีข้อมูล" | พูด "อาคาร 1 โทร 0-0000-0000" (ค่าตัวอย่าง) | ไม่พูดค่าตัวอย่าง · ใช้เบอร์จริงในตั้งค่าถ้ามี |

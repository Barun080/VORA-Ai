# หน้ามือถือธีมใหม่ + คิวอาร์ที่ไม่ค้าง IP เดิม (25 พ.ย. 2569)

## หน้ามือถือ (/m/)
- เปลี่ยนจากสีน้ำเงินบลูปริ้นเป็นธีมเดียวกับหน้าจอหุ่นยนต์ (แดง VORA) — **มืด/สว่างตามที่หน้าจอบนตัวหุ่นยนต์ตั้งไว้**
  (หน้าจอหุ่นส่ง `POST /api/kiosk/theme` เมื่อเปลี่ยนธีม/เปิดเครื่อง · รับเฉพาะเครื่องบนตัวหุ่นยนต์ · `/api/kiosk/config` คืน `theme`)
- แถบหัว โลโก้ แท็บ ฟองข้อความ ชิปคำถาม การ์ดสาขา/ข่าว หน้าให้คะแนน ใช้ชุดสีเดียวกัน · พื้นหลังภาพเดียวกับหน้าจอหุ่น (จางลง)
- ปุ่ม 🎤 พูดถาม: แสดงเฉพาะเมื่อเปิดผ่าน https และเบราว์เซอร์รองรับ (Chrome/Android, Safari iOS) — ไม่รองรับ = พิมพ์ได้ตามเดิม
- หน้าใบสมัคร (apply.html): แถบหัวเป็นสีแดง (ตัวฟอร์ม A4 ยังขาวสำหรับพิมพ์)

## คิวอาร์ (ปัญหาเปลี่ยนเครือข่าย)
- `app/netaddr.py`: เลือก IP วง LAN — ข้าม VPN (Radmin 26.x, Hamachi 25.x, Tailscale 100.64/10), 127.0.0.1, 169.254.x · ลำดับ เส้นทางหลัก → 192.168 → 10 → 172.16
- หน้าจอหุ่นขอที่อยู่ใหม่ทุกครั้งที่กดคิวอาร์ (`GET /api/kiosk/mobile_url`) และทุก 60 วินาที → เปลี่ยนเครือข่ายไม่ต้องรีเฟรช
- ไม่มีเครือข่าย LAN → ป๊อปอัปแสดงคำเตือนแทนคิวอาร์ที่สแกนไม่ได้
- ใช้ https อัตโนมัติเมื่อเปิด https อยู่ (lan_setup.bat) — มือถือครั้งแรกต้องกด "ขั้นสูง › ดำเนินการต่อ"
- หลังบ้าน › จอในวง LAN › "คิวอาร์สำหรับมือถือ": ดูที่อยู่ที่ใช้อยู่ + เลือก/ล็อกที่อยู่เอง (ผู้ดูแล) · ลำดับ VORA_PUBLIC_URL → ที่ล็อกไว้ → อัตโนมัติ
- แนะนำ: ล็อก IP เครื่องหลักที่เราเตอร์ (DHCP reservation) · มือถือต้องอยู่ Wi-Fi วงเดียวกัน และ Wi-Fi ต้องไม่กันเครื่องคุยกัน (client isolation)

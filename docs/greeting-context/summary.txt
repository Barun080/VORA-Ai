context selection (first match wins)
  1 open presentation page sent by the kiosk: departments->program, admission->admission, news->activity, college->general (also accepts context names)
  2 admission period (a published admission news item with a real event date within 60 days = Time Portal "important") -> admission,
    but at most 1 greeting in every 3 (not if either of the previous 2 greetings was admission) so it does not override kiosk every time
  3 trigger face/gesture/touch/patrol -> kiosk
  4 otherwise / unknown -> general
  parent / student pools exist but nothing in the system can detect them; used only if a caller sends context=parent|student.

anti-repetition (after the context is chosen; in memory; reset on server restart)
  candidates = pool minus (spoken in the last 5 greetings, any context) minus (already used in this context's current round); random among candidates
  none left -> clear this context's round only, then pick from pool minus the last spoken greeting (prefer ones not in the last 5)
  repetition key = spoken text without emoji (same sentence with a different emoji = same greeting). No retry loop.

emoji: display text may carry one emoji (per context; some sentences deliberately have none). Sent only when the caller declares emoji:true
  (new kiosk; it strips emoji in speechChunks/normalizeForSpeech before TTS — existing behaviour, not duplicated). Old designs do not send it -> no emoji.

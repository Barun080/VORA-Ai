# หน้าจอผู้ใช้ VORA ตามภาพ Reference + ธีมมืด/สว่าง + อวตาร VORA ตัวจริง (8 พ.ย. 2569)

งานนี้ปรับเฉพาะ **ชั้นหน้าจอ (Presentation)** ของ `http://localhost:8000/` — ไม่ได้แก้ Backend, API, AI/RAG, ฐานข้อมูล, WebSocket, `voice.js`, กล้อง (`CameraManager`, `VisitorTracker`, `shared/vision.js`), Robot Bridge หรือชุดทดสอบ

สำรองก่อนแก้: `_backups/snapshots/VORA_Robot-backup-20261108-before-ui-reference.tgz` (ไม่รวม `.env` และ `.venv`)

## 1. ใช้งาน

- เปิด `start.bat` แล้วเข้า `http://localhost:8000/` เหมือนเดิม
- **เปลี่ยนธีม**: ปุ่ม ⚙ มุมขวาบน → "ธีมหน้าจอ" → มืด (ดำ-แดง) / สว่าง (ฟ้า-ขาว) — เครื่องจำค่าไว้ (`localStorage: vora.theme`)
- **เต็มจอ**: ปุ่ม ⛶ มุมขวาบน
- **เมนูเพิ่มเติม / แชท / สถานะระบบ**: แตะปุ่ม "แตะหรือเลื่อนเมาส์เพื่อดูเมนูเพิ่มเติม" ที่ขอบขวา หรือเลื่อนเมาส์ไปขอบขวา หรือกด Tab (ปิดด้วย × หรือแตะที่อื่น)
- กลับไปดีไซน์ดำ-เหลืองเดิม: ลบบรรทัด `<link rel="stylesheet" href="kiosk-reference.css">` ใน `frontend/kiosk/index.html` และตั้ง `avatar.renderer: "placeholder"`, `experience.menuLayout: "orbital"` ใน `kiosk-config.js`
- ทดสอบอวตารจำลองเดิม: `/?avatar=placeholder`

## 3. ธีม

ทั้งสองธีมใช้ตำแหน่งเดียวกันทุกอย่าง เปลี่ยนแค่ตัวแปรสี (`:root[data-vora-theme="dark|light"]`) ซึ่งชี้ตัวแปรเดิมของ `kiosk.css` (`--yellow`, `--surface`, `--line` …) ไปที่ธีม ทำให้ลิ้นชัก โหมดนำเสนอ หน้าต่าง และการ์ดเดิมเปลี่ยนตามเอง

| | มืด | สว่าง |
|---|---|---|
| พื้นหลัง | เมืองไซเบอร์ดำ-แดง + ไล่เงาดำบน/ล่าง | เมืองฟ้า + ไล่ขาวบน/ล่าง, หัวจอเป็นกระจกฝ้า |
| Accent | แดงนีออน `#FF2B3A` (ปุ่ม `#D9142A` ตัวอักษรขาว) | แดง `#E01F30` + ฟ้า `#1A73D9` |
| แผง | กระจกดำ 74% | กระจกขาว 80% |
| ตัวอักษร | ขาว / `#C8CAD1` | `#0B1A2E` / `#3A4C63` |

ฟอนต์: Anuphan (ไทย ฟอนต์หลักของระบบ ฝังในเครื่อง) + Inter (อังกฤษ)

## 4. อวตาร

สถานะที่เชื่อมแล้ว (มาจาก AvatarController / Event เดิมทั้งหมด): **พร้อมใช้งาน** (หายใจ กะพริบตา ขยับผม) · **ทักทาย** (พูด + ข้อความ) · **กำลังฟัง** (แท่งเสียง/ไมค์เขียว) · **กำลังคิด** (ท่าเท้าคาง ถ้าคิดนานกว่า 0.35 วิ) · **กำลังพูด** (ปากขยับ) · **ขัดข้อง** (ป้ายสถานะ + วงแหวนสีแดงที่พื้น ไม่ทั้งจอ) · มองตามผู้เข้าชมจากกล้องเดิม

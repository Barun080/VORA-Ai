# ประชาสัมพันธ์อัตโนมัติรอบใหม่: ประกาศเฉพาะตาราง + ภาพ/วิดีโอกลางจอ + รอคุยจบ (27 พ.ย. 2569)

## สิ่งที่เปลี่ยน
| ส่วน | รายละเอียด |
|---|---|
| ประกาศเฉพาะตาราง | วอร่าไม่พูดข่าวหรือสาขาเองทุก 90 วินาทีแล้ว พูดเฉพาะรายการในหลังบ้าน › ตารางประชาสัมพันธ์ และปุ่ม "ประกาศทันที" |
| ช่วงหน้าจอว่าง | เลือกได้ในหน้าตารางประชาสัมพันธ์: **หมุนแสดงภาพข่าว/สาขา (ไม่พูด)** เป็นการ์ดมุมขวา แตะเพื่อเปิดรายละเอียด หรือ **ไม่แสดงอะไรหมุน** (ค่า `idle_mode` = rotate/off) หน้าจอใช้ค่าใหม่ภายใน 1 นาที |
| ประเภทงานใหม่ | **แนะนำสาขาที่เลือก** (`announce_program`) เลือกสาขาแล้วระบบเติมข้อความจากข้อมูลสาขาให้ แก้ต่อได้ ไม่มีข้อมูลระดับ = ไม่พูดคำว่า "ระดับ" |
| ฟอร์มตาราง | เลือกประเภทงานก่อน แล้วรายการเป้าหมายจะเปลี่ยนตามประเภท (ข่าว/กิจกรรม/รับสมัคร · สาขา · เส้นทาง) · ตารางแสดงชื่อข่าว/สาขาที่เลือก · ตรวจค่า (ต้องเลือกเป้าหมาย / มีข้อความ / มีสื่อ) |
| ภาพและวิดีโอ | ป๊อปอัปใหญ่กลางจอพร้อมเสียงประกาศ · ข่าว/สาขาใช้ภาพหรือวิดีโอของตัวเอง (สาขาไม่มีภาพหลัก = ใช้ภาพบรรยากาศรูปแรก) · ช่อง "วิดีโอหรือรูปภาพ" ในตารางมีผลก่อน และแยกรูปกับวิดีโอตามนามสกุลไฟล์ |
| วิดีโอมีเสียง | ระหว่างวอร่าพูด วิดีโอปิดเสียง → พูดจบแล้วเปิดเสียงวิดีโอเล่นต่อจนจบคลิป แล้วปิดป๊อปอัป · แตะจอ / เริ่มพูด / มีคำตอบใหม่ = ปิด |
| ระหว่างคุย | ประกาศปกติ (1–4 ดาว) ขึ้นเป็น**กล่องข้อความเงียบ**ในแชท (ไม่พูด ไม่มีภาพ) แล้ว**ประกาศเต็มเมื่อคุยจบ** (คนเดินออก หรือเงียบ 45 วินาที แล้วรออีก 8 วินาที) · **ด่วน 5 ดาว / ประกาศทันที** แทรกได้ · รอเกิน 30 นาที = หมดเวลา |
| เลิกทิ้งประกาศ | เดิมคุยนานเกิน 3 นาที ประกาศถูกข้าม (`skipped_busy`) · ตอนนี้เซิร์ฟเวอร์ส่งไปให้หน้าจอรอเอง |
| โควตาต่อชั่วโมง | การ์ดหมุนเวียนไม่นับเป็นการประกาศแล้ว (เดิม: นับทุก 12 วินาที ทำให้ตารางโดน "เกินโควตา" ภายในไม่กี่นาที) |
| ช่วงงดเสียง | หน้าจอรับค่า `quiet_hours` และใช้กับโหมดเดิมด้วย · ประกาศตามตารางยังถูกงดฝั่งเซิร์ฟเวอร์เหมือนเดิม (ยกเว้น 5 ดาว) |

## สวิตช์
`VORA_PR_SCHEDULE_ONLY=0` ใน `.env` แล้วรีสตาร์ต จะกลับเป็นแบบเดิมทุกส่วน คือหน้าจอว่างพูดเอง, ประกาศรอได้ 3 นาที และใช้ช่องเดิม "พูดประชาสัมพันธ์เมื่อหน้าจอว่าง"

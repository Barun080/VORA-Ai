### ปัญหาที่พบและแก้ระหว่าง Regression
1. **โฟกัสคีย์บอร์ดไม่ย้ายเข้าพื้นที่นำเสนอ** (Gate 1 ข้อ 11 ล้ม 1 ครั้ง): เดิมย้ายโฟกัสใน `requestAnimationFrame` ซึ่งหน่วงได้เกิน 1 วิบนเครื่องที่ MediaPipe ใช้ CPU หนัก → ย้ายโฟกัสทันที (พื้นที่ถูกแสดงก่อนแล้ว) + สำรองใน rAF
2. **ลำดับ Event การทักทายไม่แน่นอน** (Idle ข้อ 5b ล้ม 2 ครั้งติด — เคยล้ม 1 ครั้งใน Phase 1 ซึ่งตอนนั้นสรุปว่าไม่เสถียร): ตรวจพบว่า `speakAs()` ส่ง `AVATAR_IDLE` *ก่อน* `GREETING_FINISHED` และ `AVATAR_IDLE` ที่ตามหลังมาจากข้อความสถานะหุ่นยนต์ทาง WebSocket โดยบังเอิญ ลำดับที่เอกสาร `kiosk-redesign.md` กำหนด (`GREETING_FINISHED → AVATAR_IDLE`) จึงขึ้นกับจังหวะเวลา — อวตารกลับสู่สถานะว่างถูกต้องเสมอ แต่ลำดับ Event ไม่แน่นอน → แก้ที่โค้ด: ส่งสถานะอวตารซ้ำหลัง `GREETING_FINISHED` (`syncAvatar()`) **ไม่ได้แก้ผลที่คาดหวังของชุดทดสอบ** · ข้อสรุปใน Phase 1 Report ที่ว่า "ชุดทดสอบไม่เสถียร" จึงไม่ครบ — สาเหตุจริงคือข้อนี้

## แก้ไขหลังใช้งานจริง (1 พ.ย. 2569 14:40)

**อาการ (ผู้ใช้รายงานพร้อมภาพหน้าจอ):** เส้นทางการสมัครขั้น "อาชีพ" แสดงสาขาเมคคาทรอนิกส์และหุ่นยนต์ (ปวส.) แต่กล่องคำพูดของอวตารพูดถึงสาขาช่างยนต์ (ปวช.)

**สาเหตุ:** สาขาที่เลือกในเส้นทางมีอยู่เฉพาะบนหน้าจอ ไม่ได้ส่งให้ AI — AI ใช้ "บริบทการสนทนา" ของตัวเอง (`ctx["program_id"]` = สาขาที่คุยล่าสุด) เมื่อถามแทรกโดยไม่ระบุชื่อสาขา เช่น "สาขานี้เรียนอะไร" / "จบแล้วทำงานอะไร" จึงตอบสาขาเดิม · ทำซ้ำได้ทุกครั้งผ่าน `/api/chat` · Gate 3 เดิมทดสอบการถามแทรกด้วยคำถามค่าเทอมซึ่งไม่ขึ้นกับสาขา จึงไม่พบ

**การแก้ (เข้ากันได้ย้อนหลัง):**
- `POST /api/chat` รับฟิลด์ไม่บังคับ `context_program_id` → ตั้งเป็นสาขาของบริบทก่อนตอบ (เฉพาะสาขาที่เผยแพร่) · ชื่อสาขาที่ระบุในคำถามยังสำคัญกว่า · ไม่ส่งฟิลด์ = พฤติกรรมเดิมทุกอย่าง
- หน้าจอส่งสาขาที่กำลังแสดงในโหมดนำเสนอ (`PresentationView.currentProgramId()`): เส้นทางขั้นสาขาเป็นต้นไป · รายละเอียดสาขา · แผนผังความรู้ที่โฟกัสสาขา/อาชีพ
- ไม่แก้ AI Engine / ฐานข้อมูล

**ทดสอบเพิ่ม:** `backend/tests/test_chat_context.py` 5 กรณี (บริบทหน้าจอแทนบริบทเก่า, ไม่ส่ง = เหมือนเดิม, ชื่อในคำถามชนะ, Session ใหม่, สาขาไม่มี/ไม่เผยแพร่ถูกละเลย) · Gate 3 ข้อ 14 (ทำซ้ำสถานการณ์จากภาพหน้าจอ: คุยเรื่องช่างยนต์ก่อน → เส้นทางไปเมคคาทรอนิกส์ → ถาม "สาขานี้เรียนอะไร", "จบแล้วทำงานอะไร" และถามจากแผนผังความรู้) → Gate 3 = **15/15**

# แก้ log ให้ปลอดภัยและอ่านง่าย (21 พ.ย. 2569)

> สถานะ: **ทำเสร็จแล้ว** · ทดสอบอัตโนมัติผ่าน + ทดสอบกับเซิร์ฟเวอร์จริง (uvicorn) แล้ว · ยังไม่ได้รันบนเครื่อง Windows ของทีม

## 1. ทำอะไร

| # | ปัญหาเดิม | แก้เป็น |
|---|---|---|
| 1 | หน้าต่าง `start.bat` มีบรรทัด `HTTP Request: GET https://www.gstatic.com/generate_204 ...` ทุก 15 วินาที (ตัวตรวจเน็ตของงาน F) → log อ่านยาก | **ซ่อนเฉพาะบรรทัดตรวจเน็ตที่สำเร็จ** · ตอนเน็ตล่ม/กลับมายังมีข้อความ `[network] ตรวจไม่พบอินเทอร์เน็ต — เปลี่ยนเป็นโหมดฐานความรู้` / `[network] อินเทอร์เน็ตกลับมาแล้ว` · คำขอ httpx อื่น (เช่น เรียก AI) ยังพิมพ์ตามเดิม |
| 2 | **ความปลอดภัยระดับ HIGH (เอกสารฉบับ C ข้อ 26)**: หน้าหลังบ้านเชื่อม WebSocket ด้วย `/ws?role=admin&token=<รหัส JWT>` และ uvicorn พิมพ์ที่อยู่เต็มลง log → ใครเห็นหน้าต่าง/ภาพหน้าจอ/ข้อความที่คัดลอกไป นำรหัสไปเข้าหลังบ้านได้จนหมดอายุ (12 ชม.) | **ปิดบังรหัสก่อนพิมพ์**: `token=…`, `access_token=…`, `Authorization: Bearer …` → `***` ในทุก log ของ uvicorn / httpx / vora · **การล็อกอินและการเชื่อมต่อทำงานเหมือนเดิมทุกประการ** (เปลี่ยนเฉพาะข้อความที่พิมพ์) |

ตัวอย่างจากเซิร์ฟเวอร์จริงหลังแก้:
```
INFO:     127.0.0.1:55258 - "WebSocket /ws?role=admin&token=***" [accepted]
INFO:     127.0.0.1:55272 - "GET /api/health?token=*** HTTP/1.1" 200 OK
WARNING vora: [network] ตรวจไม่พบอินเทอร์เน็ต — เปลี่ยนเป็นโหมดฐานความรู้ (ConnectError)
```
ตรวจซ้ำ: นับจำนวนครั้งที่รหัสจริงปรากฏใน log = **0**

## 2. ทำไมใช้วิธีนี้

- **ตัวกรอง log (logging.Filter ของ Python)** แก้ตรงจุดที่รั่ว (ข้อความที่พิมพ์) โดยไม่เปลี่ยนวิธียืนยันตัวตน → ไม่กระทบหน้าหลังบ้าน หน้าจอหุ่น ชุดทดสอบเดิม และเสี่ยงต่ำก่อนประกวด
- ทางที่แข็งแรงกว่า (ส่งรหัสทางข้อความแรกของ WebSocket แทนการใส่ในที่อยู่) ต้องแก้ทั้งหน้าหลังบ้าน เซิร์ฟเวอร์ และชุดทดสอบความปลอดภัยหลายชุด → เก็บไว้เป็นงานหลังประกวด
- ไม่มี package ใหม่ · ไม่แก้ `.env` · ไม่มี migration

## 4. ข้อจำกัดที่ยังเหลือ

- รหัสยังอยู่ใน **ที่อยู่ของ WebSocket** (ฝั่งเบราว์เซอร์/เครือข่าย) แต่ไม่ถูกพิมพ์ลง log แล้ว · ระบบยังเป็น HTTP ธรรมดา (ข้อ HIGH อีกข้อในเอกสารฉบับ C: ใช้เครือข่ายแยก/HTTPS)
- log เก่าที่เคยพิมพ์ไปแล้ว (เช่น ข้อความที่คัดลอกในแชต 21 พ.ย. 22:30) ยังมีรหัสเดิม — รหัสนั้นหมดอายุเองภายใน 12 ชั่วโมงหลังล็อกอิน

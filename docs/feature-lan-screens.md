# ใช้งานจากเครื่องอื่นในวง LAN — หน้าจอหุ่นยนต์ + หลังบ้าน (25 พ.ย. 2569)

## ตั้งค่าครั้งเดียว (เครื่องหลัก)
1. คลิกขวา `lan_setup.bat` › Run as administrator → ติดตั้ง cryptography · สร้างใบรับรอง https (`data/certs/vora-lan.crt/.key`) · เปิด Firewall พอร์ต 8000/8443 (เครือข่าย Private/Domain)
2. ปิดแล้วเปิด `start.bat` ใหม่ → หน้าต่างเซิร์ฟเวอร์แสดงที่อยู่ LAN เช่น `https://192.168.1.20:8443/` และ `/admin/`
3. หลังบ้าน › หุ่นยนต์ › **จอในวง LAN** มีที่อยู่ให้คัดลอก

## เครื่องอื่น
- เปิด `https://<IP>:8443/` (หน้าจอหุ่นยนต์) หรือ `/admin/` · ครั้งแรกกด "ขั้นสูง" › "ดำเนินการต่อ" (ใบรับรองสร้างเอง)
- หน้าจอหุ่นยนต์จะขึ้นรหัส 4 ตัวมุมล่างซ้าย → ผู้ดูแลกด **อนุมัติ** ในหน้า "จอในวง LAN" (ตรวจรหัสให้ตรง) → ได้สิทธิ์ภายใน ~15 วินาที
- หลังบ้าน: ล็อกอินและสิทธิ์ผู้ใช้เหมือนเดิม (ไม่ต้องอนุมัติเครื่อง)

## สิทธิ์
| | เครื่องหลัก (localhost) | จอที่อนุมัติ | ยังไม่อนุมัติ/ปิดสิทธิ์ |
|---|---|---|---|
| ถาม-ตอบ | ไม่จำกัด | ไม่จำกัด | จำกัด 30 ครั้ง/นาที (แบบมือถือ) |
| ประกาศ/คำสั่งพูดแบบสด (WebSocket kiosk) | ✓ | ✓ | ✗ |
| ทักทายอัตโนมัติ · กล้องจำป้าย | ✓ | ✓ | ✗ |
| สั่งท่า/การเคลื่อนไหวหุ่นยนต์จริง | ✓ | ✗ | ✗ |
| เปลี่ยนสถานะหน้าจอหลักในหลังบ้าน | ✓ | ✗ | ✗ |
| ไมค์/กล้อง | ✓ | ต้องเปิดผ่าน https | ต้องเปิดผ่าน https |
ปุ่มหยุดหุ่นยนต์ฉุกเฉิน (`/api/robot/stop`) กดได้จากทุกจอเหมือนเดิม (เพื่อความปลอดภัย)

## การทำงาน
- `kiosk/screen-link.js` สร้างกุญแจสุ่ม 128 บิตเก็บใน localStorage (`vora.screenKey`) · `shared/api.js` แนบ `X-VORA-Screen` ทุกคำขอ และ `&screen=` ใน WebSocket kiosk
- เซิร์ฟเวอร์เก็บเฉพาะ sha256 ของกุญแจ (ตารางใหม่ `kiosk_screens` สร้างอัตโนมัติ ไม่ต้อง migrate) · แคชผล 10 วินาที · รออนุมัติได้สูงสุด 50 จอ
- `public.is_display_kiosk` = เครื่องหลัก หรือ จอที่อนุมัติ · การสั่งหุ่นยนต์ยังใช้ `is_trusted_kiosk` (VORA_KIOSK_TRUSTED_HOSTS) เท่านั้น
- `backend/serve.py`: http 8000 + https 8443 ในโปรเซสเดียว (lifespan ทำงานครั้งเดียว — ไม่มีตัวตั้งเวลา/พอร์ตหุ่นยนต์ซ้อน) · ไม่มีใบรับรอง = http อย่างเดียวเหมือนเดิม · start.bat เรียก serve.py (คำสั่งเดิมเก็บไว้เป็นหมายเหตุ)
- `scripts/make_lan_cert.py`: ใบรับรองใส่ localhost ชื่อเครื่อง และทุก IP ของเครื่อง · รันซ้ำจะสร้างใหม่เฉพาะเมื่อ IP เปลี่ยนหรือใกล้หมดอายุ (`--force` บังคับ · `--ip` เพิ่ม IP)

## สวิตช์
- `VORA_LAN_SCREENS=0` → จอจากเครื่องอื่นเป็นแบบมือถือทั้งหมด (เหมือนก่อนหน้านี้)
- `VORA_HTTPS_PORT=0` → ไม่เปิด https · เปลี่ยนพอร์ตได้ (ต้องแก้ Firewall ใน lan_setup.bat ด้วย)

## ข้อควรระวัง
- เปลี่ยนรหัสผ่านผู้ดูแลเริ่มต้นก่อนเปิดให้เข้าในวง LAN
- ล็อก IP เครื่องหลักที่เราเตอร์ ถ้า IP เปลี่ยนให้รัน lan_setup.bat ใหม่
- ไฟล์ `data/certs/vora-lan.key` เป็นความลับ

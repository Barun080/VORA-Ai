# ตอบคำถามสาขาให้ตรงประเด็น (23 พ.ย. 2569)

## ปัญหาที่พบ
ทีมทดลองในหน้าสมองโปร่งใส 23 พ.ย. 2569 แล้วพบว่า:

- **"มีแผนกเทคโนโลยีคอมพิวเตอร์ไหม"** ได้คำตอบ "สาขาเทคโนโลยีคอมพิวเตอร์ ฮาร์ดแวร์ ระบบปฏิบัติการ เครือข่าย และดูแลระบบค่ะ" ไม่ได้ตอบว่า "มี"
- **"เรียนเกี่ยวกับอะไรบ้าง"** (ถามต่อ) ได้ประโยคเดียวกันทุกตัวอักษร

สาเหตุอยู่ที่โค้ดเดิม: ทุกคำถามที่ระบบเข้าใจว่าเป็น "รายละเอียดสาขา" ตอบด้วยแม่แบบเดียวกัน (ชื่อสาขา + คำอธิบาย) ไม่ว่าจะถามอะไร ปัญหานี้เกิดกับคำถามอย่าง "คอมเรียนกี่ปี" และ "ยากไหม" ด้วย ซึ่งได้คำอธิบายสาขาที่ไม่ตรงคำถาม

## ทำอะไร
ไฟล์ใหม่ `backend/app/ai/program_answer.py` แยก **ประเด็นที่ถาม** แล้วเลือกข้อมูลจากช่องของสาขาให้ตรงกับประเด็น:

| ประเด็น | ตัวอย่างคำถาม | คำตอบ |
|---|---|---|
| มีหรือไม่ | มี…ไหม, เปิดสอน…ไหม | "มีค่ะ วิทยาลัยมีสาขา… เปิดสอนระดับ… เรียนเกี่ยวกับ… จบแล้วทำงานเป็น…" |
| เรียนอะไร | เรียนอะไร, เรียนเกี่ยวกับอะไรบ้าง | "สาขา…เรียนเกี่ยวกับ…ค่ะ" ต่อด้วยว่าเหมาะกับใคร |
| เหมาะกับใคร | เหมาะกับใคร, ใครควรเรียน | ข้อความจากช่อง "เหมาะกับ" |
| แนะนำสาขา | ชอบคอมควรเรียนสาขาไหน | "แนะนำสาขา…ค่ะ เหมาะกับ…" |
| จบแล้วทำงานอะไร | (ตัดสินตามเดิม) | ข้อความตามเดิม |
| ภาพรวม | …คืออะไร, ชื่อสาขาเฉย ๆ | เรียนอะไร + อาชีพ |
| **เรื่องเฉพาะ** | กี่ปี, ค่าเทอม, ทุน, ยากไหม, ต่อ ป.ตรี, ฝึกงาน, ที่ไหน | **ไม่ตอบจากช่องสาขา** แต่ค้นฐานความรู้ โดยเติมชื่อสาขาให้ถ้าถามต่อ แล้วให้ AI เรียบเรียงและผ่าน Guard ตามปกติ ถ้าไม่มีข้อมูลจะตอบตรง ๆ ว่า "เรื่องนี้ของสาขา…ยังไม่มีข้อมูลในระบบค่ะ แนะนำสอบถามงานทะเบียน… ที่บอกได้ตอนนี้คือ…" และ**บันทึกเป็นคำถามที่ตอบไม่ได้** ให้เจ้าหน้าที่เติมข้อมูล |

หลักการ:
- ใช้เฉพาะข้อมูลในฐานข้อมูล ไม่แต่งเพิ่ม
- ระดับที่เปิดสอนพูดถึงเฉพาะเมื่อมีข้อมูล
- ช่องที่ว่างจะไม่ถูกพูดถึง
- ใช้เวลาไม่ถึง 1 ms และไม่เรียก AI ภายนอก

ในหน้าสมองโปร่งใส ขั้นที่ 1 แสดงเพิ่ม:
- "ประเด็นที่ถาม: …"
- "สาขาจากคำถามก่อนหน้า: …" เมื่อเป็นการถามต่อ

## ข้อจำกัด / สิ่งที่ทีมควรทำ
- **ความฉลาดของคำตอบขึ้นกับข้อมูล:** ข้อมูลสาขาที่นำเข้าเป็น "คำอธิบายแนะแนว" สั้น ๆ และยังไม่มีระดับที่เปิดสอน ควรเติมข้อมูลในหลังบ้าน > หลักสูตร/สาขา (ระดับ ปวช./ปวส. คำอธิบาย อาชีพ เหมาะกับใคร) และเพิ่ม FAQ รายสาขา เช่น กี่ปี วิชาที่เรียน ค่าเทอม ระบบจะตอบเรื่องเฉพาะได้ทันทีโดยไม่ต้องฝึกโมเดล
- คำถามที่ระบบยังตอบไม่ได้จะขึ้นใน "คำถามที่ตอบไม่ได้" ให้ทีมเติมข้อมูลจากรายการนั้น
- การแยกประเด็นใช้คำบ่งชี้ ประโยคแปลก ๆ อาจตกไปที่ "ภาพรวม" ซึ่งก็ยังให้ข้อมูลถูกต้อง

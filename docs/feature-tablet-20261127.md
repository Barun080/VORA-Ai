# ใช้งานบนแท็บเล็ต/ไอแพด (27 พ.ย. 2569)

- เปิด: เครื่องในวง LAN เดียวกัน → `https://<IP เครื่องหลัก>:8443/` (หน้าจอหุ่นยนต์) หรือ `/m/` (หน้ามือถือ) · ครั้งแรกกดผ่านคำเตือนใบรับรอง · ไมค์/กล้องต้องเปิดผ่าน https
- อนุมัติจอในหลังบ้าน › หุ่นยนต์ › จอในวง LAN (ไม่อนุมัติ = ใช้ได้แบบหน้ามือถือ)
- ไอแพด: Safari › แชร์ › "เพิ่มไปยังหน้าจอโฮม" → เปิดเต็มจอแบบแอป (เพิ่ม meta apple-mobile-web-app-*)
- แก้เลย์เอาต์: เดิมความกว้าง ≤1100 px ทุกแนว = แบบเลื่อนหน้า (แท็บเล็ตแนวนอน 1024×768 ต้องเลื่อนจอ เมนูอยู่ล่างสุด)
  → ตอนนี้ แนวนอนกว้าง ≥900 px ใช้เลย์เอาต์จอใหญ่ (เมนูซ้าย แชท/แผงขวา แถบพิมพ์ล่าง ไม่ต้องเลื่อน) · แนวตั้งยังใช้แบบเดิม (พอดีจอแล้ว)
  · ป้ายสถานะมุมล่างซ้ายยกขึ้นไม่ทับแถบพิมพ์ · จอสัมผัส: ปิดกรอบไฮไลต์เวลาแตะ / ไม่ซูมเมื่อแตะสองครั้งบนปุ่ม
- จอใหญ่เดิม (>1100 px) ไม่เปลี่ยน

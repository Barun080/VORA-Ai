# กล่องตรวจข้อมูล (Sandbox) — 24 พ.ย. 2569

**สวิตช์:** `VORA_SANDBOX=1` (ค่าเริ่มต้น) · `0` = ซ่อนเมนูและปิด API (ข้อมูลในตารางยังอยู่ · ความรู้ที่อนุมัติไปแล้วยังใช้ตอบตามปกติ)

## ทำไม
ข้อมูลบางส่วนจากเอกสาร Perplexity ไม่แน่นอน เก่า หรือสองแหล่งขัดกัน (เช่น ชื่อหัวหน้าแผนกบนหน้าเว็บ ≠ ในตารางเรียน, อาคารจากรายงานปี 2564,
วิสัยทัศน์บนเว็บ ≠ ใน SAR 2568) — ไม่ควรให้ AI ตอบจนกว่าเจ้าหน้าที่ตรวจ แต่ก็ไม่ควรทิ้ง

## ใช้งาน
1. `import_sandbox.bat` (ดูก่อน) → `import_sandbox.bat --apply` (สำรองฐานข้อมูลอัตโนมัติ) · ย้อนกลับ `--undo ไฟล์`
2. หลังบ้าน → ปัญญาประดิษฐ์ → **กล่องตรวจข้อมูล (Sandbox)** (ตัวเลขข้างเมนู = จำนวนที่รอตรวจ)
3. แต่ละรายการแสดง ระดับความน่าเชื่อถือ ปีของข้อมูล เหตุผลที่ต้องตรวจ ลิงก์แหล่งอ้างอิง และตัวเลือกคำตอบ (กรณีแหล่งขัดกัน)
4. **อนุมัตินำเข้า** (ตามตัวเลือกที่ติ๊ก) · **แก้ไขแล้วอนุมัติ** (แก้คำถาม/คำตอบ/หมวด + บันทึกการตรวจ) · **ปฏิเสธ**
   อนุมัติแล้ว = สร้างความรู้สถานะอนุมัติในฐานความรู้ AI (ที่มา `sandbox`) ใช้ตอบได้ทันที
5. **ย้อนกลับมารอตรวจ** = ความรู้ที่สร้างไว้เปลี่ยนเป็นฉบับร่าง (ไม่ใช้ตอบ) ทุกการกระทำบันทึกใน Audit log

ระดับ: **A** ต้นฉบับตรง (ยืนยันว่ายังปัจจุบัน) · **B** ข้อมูลเก่า/กรอบส่วนกลาง · **C** ยังไม่ได้เปิดต้นฉบับ (ข่าว/สรุป Perplexity) · **U** แหล่งขัดกัน (ต้องเลือก)
สิทธิ์: ดูได้ทุกบทบาท · อนุมัติ/ปฏิเสธ/ย้อนกลับ = ผู้ดูแลระบบ

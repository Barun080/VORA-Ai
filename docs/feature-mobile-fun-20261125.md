# หน้ามือถือรอบ 2: สนุกขึ้น + คิวอาร์ไม่เตือน (25 พ.ย. 2569)

## ปัญหาที่แก้
- สแกนคิวอาร์แล้วมือถือขึ้น "การเชื่อมต่อไม่ปลอดภัย" เพราะคิวอาร์ชี้ https ที่ใช้ใบรับรองทำเอง (self-signed)
- หน้ามือถือมีแค่แชท/สาขา/ข่าวแบบรายการ ดูน่าเบื่อ

## สิ่งที่เปลี่ยน
| ส่วน | รายละเอียด |
|---|---|
| คิวอาร์ | โหมดอัตโนมัติใช้ `http://<IP>:<port>/m/` เสมอ จึงไม่มีหน้าเตือน (ค่าที่ปักไว้ในหลังบ้าน หรือ `VORA_PUBLIC_URL` ยังมีผลก่อนเหมือนเดิม) |
| ไมค์บนมือถือ | `kiosk/config` คืน `mobile_https_url` เมื่อ https เปิดอยู่ หน้าที่เปิดผ่าน http แล้วกด 🎤 จะมีคำอธิบายแล้วพาไปหน้า https (เตือนครั้งแรกครั้งเดียว) |
| หน้าแรก | การ์ดทักทาย, คำถามยอดฮิต, ป้ายแบบทดสอบ, แถบเลื่อนสาขา, ข่าวการ์ดภาพ |
| สาขา | ค้นหา, กรองตามกลุ่ม, การ์ด 2 คอลัมน์ (ใช้รูปหลัก → รูปบรรยากาศรูปแรก → ไอคอนสีตามรหัสสาขา) |
| รายละเอียดสาขา | สไลด์รูป, เรียนอะไร, เหมาะกับใคร, จบไปทำอะไร (ชิป), ระดับที่เปิด/ครู/กิจกรรม-ผลงาน จากฐานความรู้ที่ **อนุมัติแล้วเท่านั้น**, ปุ่มถามวอร่าเรื่องสาขานี้ (ส่ง `context_program_id`) และสมัครเรียน |
| แบบทดสอบ "สาขาไหนใช่ฉัน" | 6 ข้อ แนะนำ 3 อันดับ พร้อมข้อความว่าเป็นคำแนะนำเบื้องต้นเพื่อความสนุก ไม่ใช่การวัดผลทางการ |
| ข่าว | การ์ดภาพใหญ่ ป้ายประเภท/วันที่ กรองตามประเภท หน้ารายละเอียดมีแกลเลอรีและปุ่มแชร์ |
| คงเดิม | ลิงก์ตรง `?program=` `?news=`, 👍/👎, ให้คะแนน, สลับภาษา, ธีมตามหน้าจอหุ่นยนต์ |

## API ใหม่/เปลี่ยน
- `GET /api/programs` เพิ่ม `suits_th/suits_en` และใช้รูปบรรยากาศรูปแรกเมื่อยังไม่มีรูปหลัก
- `GET /api/programs/{id}/more` คืนคำตอบจากฐานความรู้ที่อนุมัติแล้วที่ตรงกับชื่อ/คำค้นของสาขา แยกหัวข้อ learn/level/people/activity/other (ไม่แต่งข้อมูลเอง ถ้าไม่มีก็ไม่แสดงหัวข้อนั้น)

## รูปภาพ
ยังไม่มีรูปสาขาในระบบ เจ้าหน้าที่อัปโหลดได้ที่ หลังบ้าน › หลักสูตร/สาขา (ภาพหลัก / ภาพบรรยากาศ) ระหว่างนี้แสดงไอคอนสี

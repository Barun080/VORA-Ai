# นำเข้ารายการให้กล้องจำทีละมาก (24 พ.ย. 2569)

หลังบ้าน → สอนกล้องจำป้าย → แท็บ "สิ่งที่หุ่นยนต์รู้จัก" → ปุ่ม **📰 นำเข้าจากข่าว/กิจกรรม** หรือ **📄 นำเข้าจาก Excel**

## ลำดับการทำงาน
1. เลือกข่าว (ติ๊กได้หลายข่าว เลือกประเภทโปสเตอร์/กิจกรรมต่อข่าว) หรืออัปโหลด .xlsx / .csv / .zip (Excel + รูป) → ดูตัวอย่าง แถวผิดเป็นสีแดงพร้อมเหตุผล
2. เบราว์เซอร์แตกรูป (สูงสุด 4 รูป/รายการ) เป็นภาพย่อย 10 แบบ/รูป (ภาพเต็ม + ครอป 70–95% เอียง ±10° แสง 0.75–1.25 คอนทราสต์) แล้วแปลงเป็นเวกเตอร์ — รูปไม่ออกนอกเครื่อง
3. บันทึกเป็น **รอตรวจ**: ป้ายถูกปิด (active=False) หุ่นยนต์ไม่ใช้ และไม่ถูกนำไปฝึก
4. เจ้าหน้าที่ตรวจ → ✓ ยืนยัน (ทีละรายการหรือเลือกหลายรายการ) / ✕ ไม่ใช้ (ลบป้าย ภาพตัวอย่าง รายละเอียด)
5. กด "ฝึกโมเดลจำภาพใหม่" เอง (ไม่ฝึกอัตโนมัติ)

## Excel แม่แบบ
- ปุ่ม "ดาวน์โหลดแม่แบบ" → แผ่นงาน "วิธีใช้" + แผ่นงานละประเภท (ป้าย / โปสเตอร์ / กิจกรรม / วัตถุ / ผลงาน) ช่องต่างกันตามประเภท
- หัวคอลัมน์มีรหัสในวงเล็บ เช่น `หัวข้อ (title)` — ระบบอ่านจากรหัสนี้ · แถว "ตัวอย่าง:" ถูกข้าม
- ช่อง "รูป": ชื่อไฟล์ใน zip (ไม่สนตัวพิมพ์เล็ก/ใหญ่ หรือโฟลเดอร์) หรือ /uploads/... · ลิงก์ https:// ภายนอกใช้ได้แค่ในป๊อปอัป (สอนกล้องไม่ได้)
- "รหัสข่าวที่ผูก" ใช้ได้กับโปสเตอร์/กิจกรรม ช่องที่ว่างจะดึงจากข่าว
- .csv ต้องมีคอลัมน์ `ประเภท (kind)` (sign/poster/event/object/product)
- อ่าน/เขียน Excel ด้วย `app/ai/xlsx_lite.py` (ไลบรารีมาตรฐาน ไม่ต้องติดตั้ง openpyxl)
- รูปใน zip เก็บที่ `data/uploads/vision-import/` (ตั้งชื่อใหม่ ใช้เฉพาะไฟล์ .png .jpg .jpeg .webp ≤ 10MB สูงสุด 300 รูป)

## API (`app/routers/vision_import.py`)
`GET status · GET news · GET template · POST parse · POST batch · POST approve · POST reject` ภายใต้ `/api/admin/vision/import/`
batch ≤ 50 รายการ/ครั้ง (หน้าเว็บส่งทีละ 5) · ภาพตัวอย่าง ≤ 120/รายการ · ตรวจขนาดเวกเตอร์ให้ตรงกับของเดิม · reject ลบได้เฉพาะที่ยังรอตรวจ

## ตาราง/สวิตช์
- ตารางใหม่ `vision_pending` (สร้างอัตโนมัติ ไม่ต้อง migrate) · รอตรวจ = มีแถว + ป้ายยังปิด (ถ้าเปิดใช้งานที่ "ตั้งค่า" เอง ถือว่ายืนยันแล้ว)
- `ai/training._pending_labels` ข้ามรายการรอตรวจตอนฝึก
- สวิตช์ `VORA_VISION_IMPORT=0` ซ่อนปุ่มนำเข้า (ต้องเปิด `VORA_VISION_DETAIL` ด้วย)

# ระบบปัญญาประดิษฐ์ของ VORA

## 1. กระบวนการตอบคำถาม (Answer Pipeline)

```
เสียง/ข้อความ → ตรวจภาษา (ไทย/อังกฤษ) → ปรับข้อความให้เป็นมาตรฐาน (ตัดคำลงท้าย ตัวอักษรซ้ำ)
  → จำแนกเจตนา (Intent Classifier ที่ฝึกเอง)  → ตรวจหาสาขาที่พูดถึง + บริบทการสนทนา
  → ถ้าเป็นเจตนาที่มีข้อมูลโครงสร้าง (รายชื่อสาขา รายละเอียดสาขา อาชีพ ข่าวล่าสุด) → ตอบจากฐานข้อมูลโดยตรง
  → ไม่เช่นนั้น ค้นคืนความรู้ที่อนุมัติแล้ว (Hybrid Retrieval) → ตรวจเกณฑ์ความมั่นใจ
       ต่ำกว่าเกณฑ์ → ตอบว่าไม่มีข้อมูล + บันทึกคำถามให้เจ้าหน้าที่ (ไม่แต่งคำตอบ)
       ผ่านเกณฑ์ → (ถ้าเปิด LLM) เรียบเรียงคำตอบจากข้อมูลที่ค้นได้เท่านั้น / (ถ้าไม่เปิด) ใช้คำตอบจากฐานความรู้
  → ตัดคำตอบให้สั้นเหมาะกับการพูด → แนบภาพ/วิดีโอ/การ์ด + ท่าทางหุ่นยนต์ + คำถามแนะนำ → บันทึกสถิติ
```

ไฟล์: `backend/app/ai/engine.py`

## 2. โมเดลจำแนกเจตนา (Intent Classifier) — ฝึกซ้ำได้

- **ข้อมูล:** ประโยคตัวอย่างไทย/อังกฤษ 15 เจตนา (เริ่มต้น 326 ประโยค) เพิ่มได้จากหลังบ้านหรือจากคำถามที่ตอบไม่ได้
- **คุณลักษณะ:** TF-IDF ของ n-gram ระดับตัวอักษร (1-4 ตัว, `char_wb`) — เหมาะกับภาษาไทยที่ไม่เว้นวรรคระหว่างคำ และทนต่อการสะกดผิด/คำพูดที่แปลงจากเสียง
- **ตัวจำแนก:** Logistic Regression หลายคลาส (`C=12`, `class_weight=balanced`) ให้ค่าความน่าจะเป็นที่ใช้ตัดสินใจ (ต่ำกว่า 0.30 ถือว่าไม่ทราบเจตนา)
- **การวัดผล:** Stratified K-Fold Cross Validation (k ≤ 5) รายงาน Accuracy, Macro-F1, ผลรายเจตนา, Confusion Matrix และประโยคที่ทายผิด
- **การเลือกแบบจำลอง (ทดลองด้วย 5-fold CV กับข้อมูลชุดเริ่มต้น):**

| คุณลักษณะ | ตัวจำแนก | Accuracy |
|---|---|---|
| char_wb 1-4 | Logistic Regression | 0.59 |
| char_wb 2-4 | Logistic Regression | 0.58 |
| word (ตัดคำด้วย PyThaiNLP newmm) 1-2 | Logistic Regression | 0.53 |
| char + word | Linear SVM | 0.58 |
| char 1-3 | Complement Naive Bayes | 0.57 |

  เลือก char_wb 1-4 + LR เพราะแม่นที่สุด ให้ความน่าจะเป็น และไม่ต้องพึ่งตัวตัดคำ
  ค่า CV ต่ำกว่าผลใช้งานจริง (ชุดทดสอบถาม-ตอบผ่าน 20/20) เพราะระบบตัดสินจากหลายสัญญาณร่วมกัน และตัวอย่างต่อเจตนายังน้อย — ตัวเลขนี้ควรสูงขึ้นเมื่อเพิ่มตัวอย่างจากการใช้งานจริง ซึ่งเป็นหลักฐานการเรียนรู้ซ้ำที่ดี
- **เวอร์ชัน:** ทุกครั้งที่ฝึกจะบันทึกไฟล์โมเดล ผลการวัด ผู้ฝึก และเปรียบเทียบกับเวอร์ชันก่อน ผู้ดูแลย้อนกลับเวอร์ชันได้

ไฟล์: `backend/app/ai/intent.py`, `backend/app/ai/training.py`

## 3. การค้นคืนความรู้ (Hybrid Retrieval)

- แหล่งข้อมูล: คำถามที่พบบ่อยที่**อนุมัติแล้ว** + หลักสูตรที่เผยแพร่ + ข่าวที่อยู่ในช่วงเผยแพร่
- ดัชนี TF-IDF char 2-4 สองชุด: ชุดคำถาม (คำถามหลัก + คำถามรูปแบบอื่น) และชุดเนื้อหา
- คะแนน = max(ความคล้ายกับคำถาม, 0.75 × ความคล้ายกับเนื้อหา) + 0.08 ถ้าหมวดตรงกับเจตนา + 0.25 ถ้าพบคำสำคัญของสาขา
- **เกณฑ์ปฏิเสธ** 0.22 (ปรับได้ใน .env) ถ้าโมเดลเจตนามั่นใจ ≥ 0.55 จะค้นซ้ำเฉพาะหมวดนั้นด้วยเกณฑ์ผ่อนลง
- สร้างดัชนีใหม่อัตโนมัติทุกครั้งที่ข้อมูลเปลี่ยน (ไม่ต้องฝึกโมเดล)

**การอัปเดตฐานความรู้ ≠ การฝึกโมเดล:** การเพิ่ม/แก้ความรู้มีผลทันทีผ่านดัชนีค้นคืน ส่วนการฝึกโมเดลคือการสร้างโมเดลเจตนา/โมเดลจำภาพเวอร์ชันใหม่จากตัวอย่าง ระบบไม่ได้ฝึก LLM ใหม่

ไฟล์: `backend/app/ai/retriever.py`

## 4. LLM (ทางเลือก)

รองรับ Gemini, OpenAI, Anthropic Claude, Typhoon (โมเดลภาษาไทย) และ Ollama (รันในเครื่อง)
ใช้เพียงเรียบเรียงคำตอบจากข้อมูลที่ค้นคืนได้ 3 รายการ มีคำสั่งห้ามแต่งข้อมูล และให้ตอบ `NO_INFO` ถ้าข้อมูลไม่พอ
มี Circuit Breaker: ล้มเหลว 3 ครั้งติด จะหยุดเรียก 60 วินาทีแล้วใช้คำตอบจากฐานความรู้แทน ผู้ใช้ไม่ต้องรอ timeout

## 5. ระบบมองเห็น (ประมวลผลในเครื่อง ไม่บันทึกภาพผู้ใช้)

| งาน | โมเดล | ใช้ทำอะไร |
|---|---|---|
| ตรวจจับใบหน้า | MediaPipe BlazeFace | ทักทายเชิงรุกเมื่อมีคนยืนหน้าหุ่น ≥ 0.7 วินาที, อวตาร์มองตาม |
| ท่ามือ | MediaPipe Gesture Recognizer | 👍 ถูกใจคำตอบ, 👎 แจ้งคำตอบผิด, ✋ หยุดพูด, ☝️ ข่าวถัดไป, ✌️ ถ่ายรูปกับหุ่น, 🤟 หุ่นทำท่าดีใจ, ✋ ตอนหน้าจอว่าง = เริ่มทักทาย |
| จำป้าย/วัตถุ | MobileNetV3 (embedding) + Logistic Regression ที่ฝึกเอง | ชูป้ายสาขาแล้วหุ่นแนะนำสาขานั้นทันที |

การฝึกโมเดลจำป้าย (Transfer Learning): หลังบ้านเปิดกล้อง → แปลงภาพเป็นเวกเตอร์ 1024 มิติในเบราว์เซอร์ → ส่งเฉพาะเวกเตอร์ไปเซิร์ฟเวอร์ → ฝึก Logistic Regression + วัดผลด้วย CV → ส่งออกน้ำหนักเป็น JSON → หน้าจอหุ่นคำนวณผลเองแบบเรียลไทม์
ป้องกันการจำผิด (open-set): ต้องมีความน่าจะเป็น ≥ 0.6 **และ** ความคล้ายกับจุดศูนย์กลางของป้ายนั้นผ่านเกณฑ์ที่คำนวณจากข้อมูล **และ** เห็นซ้ำ 3 เฟรมติด

## 6. การประเมินผล

- **ชุดทดสอบถาม-ตอบ** (หลังบ้าน > ชุดทดสอบระบบ): คำถามที่ใช้ถ้อยคำต่างจากตัวอย่างฝึก ตรวจเจตนา การตอบได้/ปฏิเสธ และคำสำคัญในคำตอบ บันทึกทุกรอบเพื่อเปรียบเทียบก่อน-หลังปรับปรุง ผลเริ่มต้น 20/20 เวลาเฉลี่ย < 10 ms (ไม่ใช้ LLM)
- **ชุดทดสอบอัตโนมัติ** (`test.bat`): 42 กรณี ครอบคลุม AI, หุ่นยนต์ 4 สถานการณ์, ความปลอดภัย, สิทธิ์ผู้ใช้, ตารางประชาสัมพันธ์, รายงาน, ความเสถียร (200 คำถามติดกัน)
- **ข้อมูลใช้งานจริง:** อัตราตอบได้ เวลาตอบ ความพึงพอใจ หัวข้อที่สนใจ ข้อผิดพลาดของระบบ (หลังบ้าน > รายงาน)

4. likely causes of "sounds like AI" (most -> least likely)
   a. voice/provider (main): Google Translate TTS is a basic dictionary-reading voice: flat intonation, pauses at every
      space between Thai phrases, no sentence-level prosody. EQ or text cleanup cannot fix timbre/prosody.
   b. prosody from piece splitting: each <=180-char piece is synthesized separately -> intonation restarts + ~0.8 s gap at joins.
   c. text normalization: small. ? ! ~ ... become spaces (Thai already uses spaces); can add a pause only where no space existed.
   d. EQ (+2 / +1.5 / +1 dB, volume 0.9): small, cannot create a robotic sound; can make it slightly brighter. A/B possible
      without code change (DevTools: VORA.speaker.eq.update({bassDb:0,clarityDb:0,trebleDb:0,volume:1}) on ?debug=1; not persistent).

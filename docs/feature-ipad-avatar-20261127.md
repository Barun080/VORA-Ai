# อวตารบน iPad/แท็บเล็ต + กล้องบน iPad (27 พ.ย. 2569)

## อวตารใหญ่เต็มจอ เห็นแต่หน้า
- สาเหตุ: อวตารวาดบน `<canvas>` ที่อยู่ใน `<foreignObject>` ของ `<svg viewBox="0 0 710 1650">` — Safari/WebKit (ทุกเบราว์เซอร์บน iPad/iPhone) ไม่ย่อเนื้อหาใน foreignObject ตาม viewBox จึงวาดขนาดจริง 710×1650 px
- แก้ (`frontend/kiosk/avatar/VoraRigRenderer.js`): บน WebKit วาง canvas ข้าง svg ในกล่องเดียวกัน แล้วจัดตำแหน่ง/ขนาดให้ทับกรอบภาพของ svg ทุกเฟรม (ตามโหมดนำเสนอ/ซูมได้) · คัดลอก opacity/filter ของ svg
- Chrome/Edge/Firefox บนคอม: แบบเดิมทุกอย่าง
- สวิตช์ทดสอบ: `?rigoverlay=1` (บังคับโหมดใหม่) · `?rigoverlay=0` (บังคับแบบเดิม)
- สำรอง: `_backups/ipad-avatar-20261127/VoraRigRenderer.js` · ทดสอบ: `frontend/tests/kiosk/rig-overlay.test.mjs`

- หน้าจอเปิดผ่าน http (`http://10.2.4.134:8000`) — เบราว์เซอร์อนุญาตกล้อง/ไมค์เฉพาะ https
- ใบรับรอง https เดิมทำไว้กับ IP 10.2.4.250 (IP เครื่องเปลี่ยนเป็น 10.2.4.134) → รัน `lan_setup.bat` แบบ Run as administrator ใหม่ แล้วรีสตาร์ต start.bat

### ทักทายเมื่อเห็นคนบนจออื่นไม่ทำงาน
- iPad/iPhone ไม่ยอมเล่นเสียงจนกว่าผู้ใช้แตะจอ → คำทักทายอัตโนมัติ (ไม่มีการแตะ) เงียบ
- แก้ (`frontend/kiosk/voice.js`): บน iOS/iPadOS แตะจอครั้งแรก = ปลดล็อก `<audio>` ตัวเดียวที่ใช้เล่นทุกประโยค + AudioContext + เสียงเบราว์เซอร์ → หลังจากนั้นทักทายมีเสียงเองได้ · คอม Windows แบบเดิม · สวิตช์ `?audiounlock=1/0`
- เงื่อนไขเดิมที่ยังต้องมี: จอต้องได้รับอนุมัติที่หลังบ้าน › จอในวง LAN (ยังไม่อนุมัติ = เซิร์ฟเวอร์ไม่ส่งคำทักทาย 403) และหลังบ้านเปิด "ทักทายอัตโนมัติ"
- สำรอง: `_backups/ipad-greet-20261127/voice.js` · ทดสอบ: `frontend/tests/kiosk/audio-unlock.test.mjs` · node 107 ผ่าน

## 1. ทำอะไร (สรุปสั้น)

เมนูใหม่ในหลังบ้าน **ปัญญาประดิษฐ์ → "สมองโปร่งใส (ดู AI คิดสด)"**
ทุกครั้งที่มีคนถาม VORA ที่หน้าจอหุ่นยนต์ หน้านี้จะแสดง **ทันที** ว่า VORA คิดอย่างไร เป็น 5 ขั้น เรียงจากซ้ายไปขวา (ค่อย ๆ ปรากฏทีละขั้น):

| ขั้น | แสดงอะไร |
|---|---|
| 1 เข้าใจคำถาม | เจตนาที่ทาย + ความมั่นใจ (%) 3 อันดับแรก · ชื่อสาขาที่พบ · เส้นทาง (เรื่องวิทยาลัย / ความรู้ทั่วไป / ไม่เหมาะสม) |
| 2 ค้นฐานความรู้ | รายการข้อมูลที่ค้นเจอพร้อมคะแนนความตรง และเกณฑ์ขั้นต่ำ (✓ = ผ่านเกณฑ์) |
| 3 AI เรียบเรียง | AI ได้รับข้อมูลกี่ชิ้น ใช้เวลาเท่าไร ใช้คำตอบที่เคยตรวจแล้ว (แคช) หรือไม่ · AI บอก "ข้อมูลไม่พอ" · AI ภายนอกล่ม |
| 4 Answer Guard 9 ข้อ | ตาราง G1–G9 สีเขียว/แดง — ข้อไหนไม่ผ่านจะกรอบแดงชัดเจน |
| 5 ป้ายแหล่งที่มา | คำตอบมาจากไหน (ข้อมูลทางการ / ฐานความรู้ / AI เรียบเรียง ฯลฯ) ระดับการตรวจสอบ และเวลาตอบรวม |

ด้านล่างมี **คำตอบที่ VORA พูดจริง** และ **ประวัติ 20 คำถามล่าสุด** (คลิกดูย้อนหลังได้) · ปุ่ม **"เต็มจอ"** สำหรับเปิดบนจอที่สองหันให้กรรมการดู

สี: เขียว = ผ่าน · เหลือง = ระวัง (มั่นใจต่ำ/ค้นไม่เจอ/AI ล่มจึงใช้ฐานความรู้) · แดง = Guard ตีกลับ · เส้นประจาง = ขั้นนั้นไม่ต้องใช้

## 2. ทำไมถึงทำ

- **กรรมการถามบ่อยที่สุดว่า "AI แต่งคำตอบเองไหม"** — เดิมเราตอบได้แค่ด้วยคำพูด หน้านี้ให้ "เห็นกับตา" ว่าทุกคำตอบผ่านการค้นข้อมูลจริงและด่านตรวจ 9 ข้อ
- ระบบ Answer Guard, ป้ายแหล่งที่มา (answer contract) และ RAG **มีอยู่แล้วแต่มองไม่เห็น** — งานนี้ไม่ได้เพิ่มความฉลาด แต่ทำให้สิ่งที่ทำไว้แล้ว "พิสูจน์ได้ต่อหน้า"
- ตรงเกณฑ์: นวัตกรรม/ความน่าเชื่อถือของ AI, การอธิบายหลักการทำงาน, ความปลอดภัยของข้อมูล
- ใช้งานจริงหลังประกวดได้ด้วย: เจ้าหน้าที่เห็นทันทีว่าคำถามไหนค้นไม่เจอ → ไปเติมฐานความรู้ได้ตรงจุด

**วิธีสาธิตที่แนะนำ (30 วินาที):** ถามคำถามปกติ ("ค่าเทอมเท่าไหร่") ให้เห็นเขียวทั้งแถว → ถามเรื่องที่ไม่มีข้อมูล ให้เห็นขั้นค้นเป็นสีเหลืองและ VORA ตอบว่าไม่มีข้อมูลแทนการแต่ง → กดเต็มจอค้างไว้ระหว่างกรรมการลองถามเอง

> หมายเหตุ: ตอนสาธิต Guard ตีกลับ (สีแดง) จะเกิดเฉพาะเมื่อ AI แต่งจริง ซึ่งเกิดไม่บ่อย ไม่ควรสัญญากรรมการว่าจะเห็นสีแดงเสมอ

## 3. ทำอย่างไร (หลักการ)

```
หน้าจอหุ่นยนต์ ── POST /api/chat ──▶ engine.answer()
                                       │  ตัวเก็บขั้นตอน (contextvar แยกต่อคำถาม)
                                       │  ├ เจตนา / เส้นทาง
                                       │  ├ ผลค้นฐานความรู้
                                       │  ├ AI เรียบเรียง + ผล Answer Guard
                                       │  └ ป้ายแหล่งที่มา
                                       ▼
                         res.trace (แอตทริบิวต์ ไม่อยู่ใน JSON)
                                       │
          JSON 18 ฟิลด์เดิม ◀──────────┤──────▶ brain.publish()
          (หน้าจอหุ่นยนต์ไม่เปลี่ยน)          ├ เก็บ 30 รายการล่าสุดในหน่วยความจำ
                                              └ WebSocket topic "ai.trace" → เฉพาะหลังบ้านที่ล็อกอิน
```

1. **บันทึก ไม่ตัดสิน** — โค้ดที่เพิ่มใน engine แค่ "จด" สิ่งที่เกิดขึ้น ไม่เปลี่ยนเงื่อนไขการตอบใด ๆ
2. **แยกต่อคำถาม** ด้วย `contextvars` — คนถามพร้อมกันหลายคน ข้อมูลไม่ปนกัน (มีชุดทดสอบถาม 3 คำถามพร้อมกัน)
3. **ไม่แตะสัญญา JSON** — ชุดทดสอบเดิมตรึง 18 ฟิลด์ของ `/api/chat` ไว้ จึงแนบ trace เป็นแอตทริบิวต์ `.trace` แบบเดียวกับ `.contract`
4. **ส่งเฉพาะหลังบ้าน** — ใช้ hub เดิม `roles=("admin",)` หน้าจอหุ่นยนต์/มือถือไม่ได้รับ
5. **ล้มไม่กระทบ** — ส่ง trace ผิดพลาดอย่างไรก็ถูกกลืนไว้ ผู้ใช้ยังได้คำตอบตามปกติ
6. หน้าจอแปลง trace เป็น 5 ขั้นด้วยฟังก์ชันล้วน `describeTrace()` (ทดสอบด้วย node ได้โดยไม่ต้องเปิดเบราว์เซอร์)

## 4. ความปลอดภัยและความเป็นส่วนตัว

| สิ่งที่ **ไม่** แสดง/ไม่เก็บ | วิธี |
|---|---|
| คำสั่งระบบ (system prompt), รหัส canary, CONTEXT เต็ม | ไม่ถูกใส่ใน trace เลย (มีชุดทดสอบตรวจ) |
| เบอร์โทร อีเมล เลขบัตร ฯลฯ ในคำถาม | ผ่าน `redact_pii` ก่อนเก็บ (มีชุดทดสอบ) |
| ไม่ลงฐานข้อมูล/ไฟล์ | เก็บในหน่วยความจำ 30 รายการ รีสตาร์ตแล้วหาย |
| คนที่ไม่ได้ล็อกอิน | `GET /api/admin/brain/recent` ต้องสิทธิ์ viewer ขึ้นไป · WebSocket admin ต้องมี token |

## 5. ใช้อะไรบ้าง

- **ไม่มีแพ็กเกจใหม่ ไม่มีค่าใช้จ่ายเพิ่ม ไม่เรียก AI เพิ่ม**

## 8. การทดสอบ

**ชุดทดสอบอัตโนมัติ** (`test_brain_trace.py` 15 ข้อ + `brain-view.test.mjs` 5 ข้อ): JSON ของ `/api/chat` ไม่มีคีย์ใหม่ · trace ครบทุกขั้น · ปิดข้อมูลส่วนบุคคล · ไม่มี system prompt/canary · AI ล่ม / NO_INFO / Guard ตีกลับ / แคช แสดงถูก · คำถามพร้อมกันไม่ปน · ต้องล็อกอิน · ส่งเฉพาะ admin · เรียงใหม่สุดก่อนและจำกัดจำนวน · ปิดสวิตช์แล้วคำตอบเหมือนเดิม · ส่งล้มไม่ทำให้แชตล้ม

**ทดสอบจริงแล้ว:** เชื่อม WebSocket ฝั่ง admin → ถามผ่าน `/api/chat` → ได้รับ `ai.trace` ทันที · ตรวจหน้าตาด้วยภาพหน้าจอ (5 การ์ด + ตาราง G1–G9)

**ยังต้องทดสอบบนเครื่องจริง (ทีมทำ):**
1. รัน `pytest` บน Windows (คาด 1040 ผ่าน)
2. เปิดหลังบ้าน → สมองโปร่งใส แล้วถามที่หน้าจอหุ่นยนต์ทั้งพิมพ์และเสียง ดูว่าขึ้นทันที
3. กด "เต็มจอ" บนจอที่สอง/โปรเจกเตอร์ ดูว่าตัวหนังสืออ่านได้จากระยะกรรมการ
4. กดจำลองเน็ตล่ม (งาน F) แล้วถาม → ขั้น AI ต้องเป็น "โหมดฐานความรู้"

## 9. ข้อจำกัด (พูดตรง ๆ กับกรรมการ)

- แสดงเฉพาะคำถามจาก `/api/chat` (พิมพ์/เสียง) — การจำภาพจากกล้องและการทักทายอัตโนมัติยังไม่แสดงในหน้านี้
- "ความมั่นใจ" ของขั้นเข้าใจคำถามคือความน่าจะเป็นของโมเดลจำแนกเจตนา ไม่ใช่ความถูกต้องของคำตอบ
- Guard ตรวจตามกฎ 9 ข้อ ลดโอกาส AI แต่งข้อมูลได้มาก แต่ **ไม่รับประกันว่าถูกต้อง 100%** (ตรงกับขอบเขตโครงการ)

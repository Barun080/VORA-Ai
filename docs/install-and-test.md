# การติดตั้งและทดสอบระบบ VORA

## 1. อุปกรณ์ที่ใช้

| ส่วน | ขั้นต่ำ | แนะนำ |
|---|---|---|
| คอมพิวเตอร์บนหุ่นยนต์ | Windows 10/11, CPU 4 คอร์, RAM 8 GB | โน้ตบุ๊ก/มินิพีซี มีกล้องและไมโครโฟน |
| หน้าจอ | 13 นิ้ว | จอสัมผัส 15-21 นิ้ว |
| กล้อง | เว็บแคม 720p | 1080p มุมกว้าง วางระดับสายตาผู้ใหญ่ |
| ไมโครโฟน/ลำโพง | ในตัวเครื่อง | ไมค์ทิศทางเดียว + ลำโพงแยก (งานประกวดมีเสียงรบกวนมาก) |
| เครือข่าย | — | Wi-Fi/ฮอตสปอตของทีมเอง สำหรับรับเสียงพูดและหน้ามือถือ |
| เบราว์เซอร์ | Google Chrome หรือ Microsoft Edge รุ่นล่าสุด | |

## 2. ขั้นตอนการติดตั้ง

1. ติดตั้ง Python 3.11+ (ติ๊ก Add to PATH) และ Google Chrome
2. คัดลอกโฟลเดอร์ `VORA_Robot` ลงเครื่อง
3. ดับเบิลคลิก `setup.bat` — สร้าง virtual environment, ติดตั้งแพ็กเกจ, สร้าง `.env`, โหลดโมเดลภาพไว้ใช้ออฟไลน์ (ต้องต่ออินเทอร์เน็ตครั้งแรก) เมื่อถามเรื่อง PostgreSQL ให้ตอบ Y (รายละเอียดใน [database.md](database.md))
4. แก้ `.env` ตามต้องการ (ช่องทางเชื่อมต่อหุ่นยนต์, LLM, เสียง)
5. ดับเบิลคลิก `start.bat` — เซิร์ฟเวอร์จะเริ่มและเปิดหลังบ้าน ถ้าเซิร์ฟเวอร์หยุดเองจะรีสตาร์ทอัตโนมัติ
6. เข้าหลังบ้าน `admin` / `vora1234` → เปลี่ยนรหัสผ่าน → ตั้งค่าชื่อสถานศึกษา → ใส่ข้อมูลสาขา ข่าว และคำถามที่พบบ่อยของจริง
7. ดับเบิลคลิก `kiosk.bat` เพื่อเปิดหน้าจอหุ่นยนต์เต็มจอ อนุญาตกล้องและไมโครโฟนเมื่อเบราว์เซอร์ถาม
8. ต่อหุ่นยนต์จริง: ตั้ง `VORA_ROBOT_DRIVER=serial` และพอร์ต COM ใน `.env` แล้วเริ่ม `start.bat` ใหม่ หรือสลับจากหลังบ้าน > หุ่นยนต์

## 3. รายการตรวจก่อนสาธิต (ทำทุกครั้ง)

- [ ] หลังบ้าน > แดชบอร์ด > สถานะระบบ เป็นสีเขียวทั้งหมด (ฐานข้อมูลพร้อม, หน้าจอหุ่นยนต์เปิดอยู่, หุ่นยนต์เชื่อมต่อ, ข้อผิดพลาด 0)
- [ ] ทดสอบพูด 1 คำถามภาษาไทย และ 1 คำถามภาษาอังกฤษ
- [ ] เดินเข้าหน้ากล้อง หุ่นยนต์ทักทายเอง
- [ ] ชูป้ายสาขา 1 ป้าย และชูนิ้วโป้ง
- [ ] กดประกาศทันทีจากหลังบ้าน 1 ครั้ง
- [ ] สั่งเดินหน้า-ถอย-เลี้ยว และวางสิ่งกีดขวาง
- [ ] กดปุ่มหยุดบนหน้าจอขณะหุ่นเดิน
- [ ] แบตเตอรี่หุ่นยนต์ ≥ 70% และคอมพิวเตอร์เสียบสายชาร์จ
- [ ] ปิดการอัปเดตอัตโนมัติของ Windows และโหมดพักหน้าจอ

## 6. การบำรุงรักษา

- **รายวัน:** ตรวจหน้า "คำถามที่ตอบไม่ได้" และ "ผลตอบรับ" เพิ่มความรู้ที่ขาด
- **รายสัปดาห์:** ฝึกโมเดลเข้าใจคำถามใหม่หลังเพิ่มตัวอย่าง แล้วรันชุดทดสอบเทียบผล
- **ก่อนวันสาธิต/ทุกสัปดาห์:** ดับเบิลคลิก `backup_db.bat` สำรองฐานข้อมูล และคัดลอก `_backups`, `data/uploads`, `data/models` ไปเก็บอีกที่
- **รายเดือน:** ลบข่าวหมดอายุ, ตรวจหน้าเหตุการณ์ระบบ
- **ฮาร์ดแวร์:** ทำความสะอาดเลนส์กล้องและเซนเซอร์ระยะ ตรวจล้อและสกรู ชาร์จแบตให้เต็มก่อนใช้งาน

## 7. ข้อควรระวัง

- อย่าให้หุ่นยนต์เคลื่อนที่ใกล้บันได ขอบเวที หรือพื้นลื่น ใช้งานในพื้นที่ที่กำหนดและมีผู้ดูแลอยู่ด้วยเสมอ
- ปุ่มหยุดฉุกเฉินบนตัวหุ่นต้องเข้าถึงได้ง่ายตลอดเวลา
- กล้องประมวลผลภาพในเครื่องเท่านั้น ระบบไม่บันทึกภาพผู้ใช้ ยกเว้นภาพตัวอย่างที่เจ้าหน้าที่ถ่ายเพื่อสอนป้าย
- ข้อมูลที่หุ่นยนต์ตอบมาจากฐานความรู้ที่เจ้าหน้าที่อนุมัติ ต้องตรวจทานความถูกต้องสม่ำเสมอ ระบบไม่รับประกันว่าคำตอบถูกทุกกรณี
- เปลี่ยนรหัสผ่านเริ่มต้นทันที และไม่เปิดพอร์ต 8000 สู่อินเทอร์เน็ตสาธารณะ

# VORA — ระบบซอฟต์แวร์หุ่นยนต์ประชาสัมพันธ์อัจฉริยะ

ซอฟต์แวร์สำหรับหุ่นยนต์ประชาสัมพันธ์ของสถานศึกษาอาชีวศึกษา ประกอบด้วย AI ถาม-ตอบจากฐานความรู้ของวิทยาลัย
ระบบเสียงไทย/อังกฤษ อวตาร์เต็มตัว ระบบมองเห็น (ทักทายเชิงรุก ท่ามือ จำป้าย) ประชาสัมพันธ์อัตโนมัติ
หลังบ้านสำหรับเจ้าหน้าที่ รายงานประเมินผล และชั้นเชื่อมต่อหุ่นยนต์ (Robot Integration Layer) พร้อมหุ่นยนต์จำลอง

> พัฒนาตามเกณฑ์ประเภทที่ 7 สิ่งประดิษฐ์ด้านนวัตกรรมและเทคโนโลยีหุ่นยนต์ประชาสัมพันธ์อัจฉริยะ ปีการศึกษา 2569
> ดูการจับคู่ฟีเจอร์กับเกณฑ์คะแนนทุกข้อได้ที่ [docs/scoring-map.md](docs/scoring-map.md)

## เริ่มใช้งานบน Windows (ครั้งแรก)

1. ติดตั้ง **Python 3.11 ขึ้นไป** จาก python.org (ติ๊ก *Add python.exe to PATH*) และ **Google Chrome**
2. ดับเบิลคลิก `setup.bat` (ติดตั้งแพ็กเกจ สร้างไฟล์ `.env` โหลดโมเดลภาพไว้ใช้ออฟไลน์ และถามว่าจะติดตั้ง PostgreSQL ไหม — ตอบ Y)
   - ถ้าติดตั้งไว้แล้วแต่ยังใช้ SQLite อยู่ ดับเบิลคลิก `setup_postgres.bat` ระบบจะติดตั้ง/เชื่อมต่อ PostgreSQL และย้ายข้อมูลเดิมให้ (ดู [docs/database.md](docs/database.md))
3. ดับเบิลคลิก `start.bat` แล้วเปิด
   - หน้าจอหุ่นยนต์: http://localhost:8000/  (หรือดับเบิลคลิก `kiosk.bat` เพื่อเปิดเต็มจอ)
   - หลังบ้าน: http://localhost:8000/admin/  ผู้ใช้ `admin` รหัส `vora1234` (เปลี่ยนรหัสทันที)
   - มือถือ: สแกน QR Code ที่การ์ด "สแกน QR" ด้านซ้ายของหน้าจอหุ่นยนต์ (มือถือต้องอยู่ Wi-Fi เดียวกัน)
   - หน้าจอหุ่นยนต์ใช้เลย์เอาต์ตามภาพ Reference + อวตาร VORA ตัวจริง ตั้งแต่ 8 พ.ย. 2569 เลือกธีม **มืด (ดำ-แดง)** หรือ **สว่าง (ฟ้า-ขาว-แดง)** ได้ที่ปุ่มตั้งค่า ⚙ มุมขวาบน (รายละเอียด: [docs/ui-reference-redesign.md](docs/ui-reference-redesign.md))
   - ดีไซน์ดำ-เหลือง (31 ต.ค. 2569): ลบบรรทัด `kiosk-reference.css` ใน `frontend/kiosk/index.html` · ดีไซน์เก่ากว่านั้นยังเปิดได้ที่ `/pastel/` และ `/classic/` ([docs/kiosk-redesign.md](docs/kiosk-redesign.md))
4. รันชุดทดสอบอัตโนมัติ: ดับเบิลคลิก `test.bat` ผลจะถูกบันทึกที่ `docs/test-results.txt`
5. สำรองข้อมูล: ดับเบิลคลิก `backup_db.bat` (ไฟล์อยู่ที่ `_backups/database`)

ระบบทำงานได้ทันทีแบบออฟไลน์ ถ้าต้องการให้คำตอบเป็นธรรมชาติขึ้นด้วย LLM ให้ใส่ API key ใน `.env` (ดู `.env.example`)

## โครงสร้างระบบ

```
หน้าจอหุ่นยนต์ (Kiosk) ─┐                         ┌─ AI Engine: Intent Model (ฝึกเอง) + Retrieval + LLM (ทางเลือก)
หน้ามือถือ (QR)        ─┼── REST + WebSocket ── Backend (FastAPI) ─┼─ ฐานข้อมูล PostgreSQL / SQLite (ข่าว หลักสูตร ความรู้ สถิติ)
หลังบ้านเจ้าหน้าที่      ─┘                         ├─ PR Scheduler (ประชาสัมพันธ์อัตโนมัติ)
                                                   └─ Robot Bridge ══ VORA Robot Protocol v1 ══ บอร์ดหุ่นยนต์ / หุ่นจำลอง
```

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `backend/app/ai/` | ประมวลผลข้อความไทย, โมเดลเจตนา, ค้นคืนความรู้, LLM, การฝึกซ้ำและประเมินผล |
| `backend/app/robot/` | โปรโตคอล, Robot Bridge, ไดรเวอร์ Serial/WebSocket, หุ่นยนต์จำลอง |
| `backend/app/routers/` | API สาธารณะ, หลังบ้าน, หุ่นยนต์, รายงาน |
| `backend/tests/` | ชุดทดสอบอัตโนมัติ 46 กรณี |
| `frontend/kiosk/` | หน้าจอหุ่นยนต์: `app.js` ตัวประสานงานบทสนทนา, `idle-ui.js` UI Controller (โหมดว่าง/ใช้งาน), `voice.js` เสียง, `kiosk-config.js` ค่าปรับแต่ง, `core/event-bus.js` Event กลางระหว่าง Controller |
| `frontend/kiosk/avatar/` | Avatar Controller แยกจากตรรกะ AI: ท่าทาง กล่องคำพูด ขยายอวตารในโหมดว่าง + ตัววาดแบบจำลอง (SVG) และแบบภาพเลเยอร์จาก PSD |
| `frontend/kiosk/camera/` | Camera & Visitor Controller: กล้องเปิดอัตโนมัติ (ครอบ MediaPipe เดิม) + Visitor Session สำหรับทักทาย |
| `frontend/kiosk/interaction/` | ลำดับความสำคัญ: หยุดฉุกเฉิน > ทักทาย > สนทนา > ประกาศ > ว่าง |
| `frontend/admin/` | หลังบ้าน |
| `frontend/mobile/` | หน้ามือถือ |
| `firmware/vora_esp32/` | เฟิร์มแวร์ต้นแบบอ้างอิงสำหรับทีมฮาร์ดแวร์ (ESP32) |
| `docs/` | เอกสารประกอบ: เกณฑ์คะแนน, โปรโตคอล, โมเดล AI, การติดตั้งทดสอบ, สคริปต์สาธิต |

## ความสามารถหลัก

- **ถาม-ตอบอัจฉริยะ** ด้วยเสียงหรือพิมพ์ ไทย/อังกฤษ จำบริบทได้ (ถามต่อ "จบแล้วทำงานอะไร") บอกตรงๆ เมื่อไม่มีข้อมูลและเก็บคำถามไว้ให้เจ้าหน้าที่
- **ทักทายเชิงรุก** กล้องเปิดเองเมื่อเปิดหน้าจอ ทักผู้เข้าชมใหม่ครั้งเดียวต่อการเข้าชม (Visitor Session + Cooldown) พักประกาศข่าวระหว่างทักแล้วกลับมาประกาศต่อ อวตาร์มองตามผู้ใช้ ไม่ใช้การจดจำใบหน้า
- **โต้ตอบด้วยภาพ** ท่ามือ 7 แบบ และป้าย/วัตถุที่สอนเพิ่มได้เองจากหลังบ้าน (Transfer Learning)
- **ตอบหลายรูปแบบ** ข้อความ เสียง ภาพ วิดีโอ การ์ด และท่าทางของอวตาร์/หุ่นยนต์
- **ประชาสัมพันธ์อัตโนมัติ** ตามเวลา/รอบเวลา, โหมดดึงดูดเมื่อว่าง, เดินประชาสัมพันธ์ตามเส้นทาง, กันการรบกวน
- **ฐานความรู้และการเรียนรู้ซ้ำ** เพิ่ม/แก้/ลบ/นำเข้า CSV, อนุมัติก่อนใช้, ฝึกโมเดลใหม่พร้อมวัดผลและย้อนเวอร์ชัน
- **รายงาน** การใช้งาน หัวข้อที่สนใจ อัตราตอบได้ ความพึงพอใจ ความเสถียร ส่งออก CSV/PDF
- **หุ่นยนต์** สั่งเคลื่อนที่/ท่าทาง, หยุดฉุกเฉิน, watchdog, หลบสิ่งกีดขวาง, เชื่อมต่อใหม่อัตโนมัติ

## ขอบเขตและข้อจำกัดที่ต้องบอกตรงๆ

- การรับเสียงพูดใช้ Web Speech API ของ Chrome/Edge ซึ่ง**ต้องต่ออินเทอร์เน็ต** ถ้าไม่มีเน็ตยังพิมพ์ แตะ และใช้กล้องได้
- การเคลื่อนที่จริงขึ้นกับฮาร์ดแวร์ ซอฟต์แวร์ทดสอบกับหุ่นจำลองแล้ว ต้องทดสอบซ้ำกับหุ่นจริงเมื่อทีมฮาร์ดแวร์พร้อม
- `firmware/vora_esp32` เป็นต้นแบบอ้างอิง ยังไม่ได้คอมไพล์หรือทดสอบบนบอร์ดจริง
- ข้อมูลสถานศึกษาในระบบเป็นข้อมูลตัวอย่าง ต้องแทนด้วยข้อมูลจริงและให้เจ้าหน้าที่ตรวจสอบก่อนใช้งาน
- การอัปเดตฐานความรู้ (Retrieval) แยกจากการฝึกโมเดล (Retrain) — ระบบฝึกซ้ำได้จริงสำหรับโมเดลเข้าใจเจตนาและโมเดลจำภาพ ไม่ได้ฝึก LLM ใหม่
